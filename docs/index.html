Everyday PDF page edits. Nothing leaves your computer.

A small Windows app for splitting, trimming, reordering and merging PDF pages. The interactive demo below is its named-range split — move the cuts and watch the filenames update with the app's own rules.

Seven operations

The app's sidebar, in order. Every example runs on the same 95-page document.

  • 01 — Split by named ranges

    Divide a PDF into named files. Each range includes its first and last page.

    You enterIntroduction · 1 · 10
    You get

    → Introduction.pdf
    → Main content.pdf
    → Appendix.pdf

  • 02 — Delete selected pages

    Remove selected pages and keep everything else.

    You enter2, 5-7, 12
    You get

    → one file, 90 pages

  • 03 — Trim start/end

    Remove pages from the beginning, the end, or both.

    You enterstart 2 · end 3
    You get

    → one file, pp. 3–92

  • 04 — Split by page count

    Create evenly sized batches from one PDF.

    You enter25
    You get

    → four files: 25, 25, 25, 20

  • 05 — Keep selected pages

    Create a PDF containing only the pages you select.

    You enter2, 5-7, 12
    You get

    → one file, 5 pages

  • 06 — Reorder pages

    Arrange selected pages in the order you enter. A page listed twice is refused, so nothing is dropped quietly.

    You enter3, 1-2, 4
    You get

    → one file: 3, 1, 2, 4

  • 07 — Merge PDFs

    Combine two or more PDFs in the order you choose.

    You enterreport.pdf + appendix.pdf
    You get

    → one file, in that order

The fine print

What SlicePDF does on every run, and what it doesn't do at all.

Every run

Never overwrites
A name that's already taken gets a number: Appendix-2.pdf.
Leaves the original alone
Your source PDF is only read, never changed.
Keeps links and bookmarks
Ones pointing at a page the new file doesn't have are dropped.
Remembers your output folder
The folder you chose last time is ready at launch. If it has moved or been deleted, files go beside the original.
Stops when you cancel
Before the next file. Files already saved stay where they are.
Stays on your computer
No uploads, no account, no tracking.

Not at all

Page previews
You work from page numbers.
Batch processing
One PDF at a time, or one set of PDFs to merge.
Password-protected PDFs
Refused when you open them. A PDF that opens without a password works.
Document properties
Title and author are not copied into the new files.
macOS or Linux
It relies on Windows font loading and Windows filename rules.
Code signing
The build is unsigned, so SmartScreen asks once.

If one of these blocks you, open an issue and say so.

Install

One executable, or two lines of Python. Both give you the same app.

The executable

  1. Download SlicePDF.exe — one file, nothing to install.
  2. Windows shows a SmartScreen warning because the file is not code-signed. Choose More info, then Run anyway.
  3. Drag a PDF onto the window, or use Choose PDF.

Get-FileHash .\SlicePDF.exe -Algorithm SHA256 — compare with SlicePDF.exe.sha256 on the latest release.
