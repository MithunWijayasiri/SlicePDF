Everyday PDF page edits. Nothing leaves your computer.

A small Windows app for splitting, trimming, reordering and merging PDF pages. Below is its named-range split, running on a 95-page document — move the cut lines and watch the filenames change.

report.pdf · 95 pages · opened read-only

Drag a cut line, or focus one and press ← →. Rename any range.

  • pp. 1–1010 pages saves asIntroduction.pdf
  • pp. 11–8070 pages saves asMain content.pdf
  • pp. 81–9515 pages saves asAppendix.pdf

Filenames here follow the app's own rules: characters Windows forbids become -, and a name already taken picks up a number. Try typing Re/port, or giving two ranges the same name.

Seven operations

The app's sidebar, in its own order. Every example runs on the same 95-page document.

  • Split by named ranges

    Divide a PDF into named files. Each range includes its first and last page.

    You enterIntroduction · 1 · 10
    You get

    → Introduction.pdf
    → Main content.pdf
    → Appendix.pdf

  • Delete selected pages

    Remove selected pages and keep everything else.

    You enter2, 5-7, 12
    You get

    → one file, 90 pages

  • Keep selected pages

    Create a PDF containing only the pages you select.

    You enter2, 5-7, 12
    You get

    → one file, 5 pages

  • Trim start/end

    Remove pages from the beginning, the end, or both.

    You enterstart 2 · end 3
    You get

    → one file, pp. 3–92

  • Split by page count

    Create evenly sized batches from one PDF.

    You enter25
    You get

    → four files: 25, 25, 25, 20

  • Reorder pages

    Arrange selected pages in the order you enter. A page listed twice is refused, so nothing is dropped quietly.

    You enter3, 1-2, 4
    You get

    → one file: 3, 1, 2, 4

  • Merge PDFs

    Combine two or more PDFs in the order you choose.

    You enterreport.pdf + appendix.pdf
    You get

    → one file, in that order

What it will not do

The limits are the point. Each of these is enforced in code, not promised in a policy.

Will not upload anything

No account, no server, no network calls, no telemetry. The whole app runs on your machine.

Will not touch your original

The source PDF is only ever read. It comes out of the operation byte for byte the same.

Will not overwrite a file

A name already in the folder becomes Appendix-2.pdf. New files are created exclusively, so a collision fails instead of replacing.

Will not guess your page numbers

Page numbers are 1-based and inclusive, and 1 <= from <= to <= total is checked before anything is written.

Will not freeze on a long job

Page work happens off the interface thread, with a progress bar while it runs.

Will not talk to you in code

Messages are plain language. There is no command line, no config file, and nothing to set up.

Install

One executable, or two lines of Python. Both give you the same app.

The executable

  1. Download SlicePDF.exe. One file, nothing to install.
  2. Windows shows a SmartScreen warning, because the file is not code-signed. Choose More info, then Run anyway.
  3. Drag a PDF onto the window, or use Choose PDF.

Check it first, if you like:
Get-FileHash .\SlicePDF.exe -Algorithm SHA256
then compare it with SlicePDF.exe.sha256 on the latest release.

From source

Needs Python 3.14 on Windows.

# clone the repository, then:
py -m pip install -r requirements.txt
py slicepdf.py
